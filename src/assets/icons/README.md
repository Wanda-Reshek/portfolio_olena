# Icons Folder

This folder contains SVG icons used in the portfolio.

## Required Icons:

1. **copy.svg** - Copy icon (two overlapping rectangles) for the email copy button
2. **arrow-right-up.svg** - External link icon (arrow pointing right-up) for CV and LinkedIn links

## How to add icons:

1. Export SVG files from Figma
2. Save them in this folder with the exact names above
3. Make sure the SVG files are optimized (remove unnecessary attributes)
