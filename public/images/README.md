## Image Specifications:

- **Aspect Ratio**: 560:360 (maintained automatically by CSS)
- **Format**: PNG (or JPG/JPEG also works)
- **Recommended dimensions**: At least 1120x720px for retina displays
- **File size**: Optimize for web (under 500KB per image recommended)

## File Paths:

Once uploaded, the images will be accessible at:
- `/images/project1-preview.png`
- `/images/project2-preview.png`
- `/images/project3-preview.png`

The code already references these paths, so once you upload the files with these exact names, they'll appear automatically on your portfolio!
